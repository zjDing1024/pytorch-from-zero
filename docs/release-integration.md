3. 新说明没有提交占位符、未验证的新commit链接或私有交付标记；新增相对链接确实指向包内文件。
4. 发布准备单独检查当前远端基线、观测新鲜度、先前发布动作结果、对最终候选清单的审阅证据和跨仓库链接。

checker的正反例使用合成文件验证拒绝路径，不能代替主项目测试或远端CI。其实际用例数量与结果见overlay包的验证报告，避免在多个文档中维护易过期数字。
