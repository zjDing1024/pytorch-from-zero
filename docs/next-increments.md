# 下一增量与验收门槛

这些是项目计划，尚未完成；节奏以用户自测与实验结果为准。

1. **模块化训练**：用原创 `nn.Module`、Dataset/DataLoader 重写当前流程，与现有全批次基线交叉验证。验收参数注册、train/eval 模式、小批次损失加权、seed/打乱行为测试。
2. **可靠恢复**：保存模型、优化器、随机状态与配置；中断后恢复到同一训练轨迹。只加载信任的 checkpoint，补异常格式与版本检查。
3. **Optimizer/Scheduler**：手写 momentum SGD 与 torch 实现对照，解释 scheduler 调用顺序，检查不同 batch size 的公平比较。
4. **真实数据与质量**：选公开授权的小型数据集，建立固定划分、泄漏检查、误差分析与多种子报告；与简单基线公平比较。
5. **运行时工程**：Docker、配置管理、日志、资源计量与测试矩阵。只有实际跑过才标已验证。
6. **GPU 能力**：取得可用 GPU 后测试 AMP、数值稳定、正确计时与显存；CPU 环境先学习原理，不虚构结果。
7. **分布式**：待单机训练与恢复稳定后再研究 DDP、采样器、梯度同步和故障恢复。

达到独立训练、恢复、测试和可解释实验的门槛后，再把这个项目作为完整训练工程求职案例。首个增量可证明材料质量和验证方法，不能单独代表岗位胜任力。
