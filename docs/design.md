# 设计、推导与可证伪实验

## 1. 形状是一项契约

令 X 为 N×D、W 为 D×K、b 为 K、Y 为 N×K。

预测 P = XW + b，残差 R = P − Y，损失 L = sum(R²)/(N K)。

由链式法则：dL/dP = 2R/(N K)，dL/dW = Xᵀ(2R/(N K))，dL/db = sum_rows(2R/(N K))。

偏置被每一行共享，所以贡献在行维相加。若 K>1 时误用 N 作分母，梯度会被放大 K 倍。测试覆盖 K=1、2、4，包括单样本单特征场景。

禁止把 Y[N] 传给 P[N,1]：减法可能广播出 N×N，损失仍能生成一个数，训练目标却已经改变。入口显式检查完整形状，而非依赖“运算没有报错”。

## 2. 三路检查与局限

1. 解析梯度：由上述公式独立写出，不调用 Autograd。
2. Autograd：构图后用 `torch.autograd.grad` 获取 W、b 的导数。
3. 中心差分：对每个参数计算 (L(θ+ε)−L(θ−ε))/(2ε)，ε=1e-6。

三者使用相同损失定义，但求导路径不同。还调用 PyTorch gradcheck 作为附加检查，不能把它当作第四个完全独立的数学证明。有限差分只在小规模 float64 平滑问题上检查；ε 过小会受舍入影响，过大有截断误差。对不可微点或低精度应另行分析。

数值差分先创建连续独立副本，避免参数为非连续视图时 `reshape` 意外复制导致原参数未被扰动。测试验证非连续输入以及函数不修改调用者参数。

## 3. 内存共享与图生命周期

转置实验用一个 3×4 连续张量，转置后 stride 从 (4,1) 变成 (1,4)。对视图写入，原张量对应位置同时变化。这个具体布局不能直接 `view(-1)`；`reshape(-1)` 创建副本，修改其元素不会反写原数据。

这只证明所选例子的行为。非连续张量可能仍有可用的 view，reshape 也可能返回视图，不能推广为“所有转置都复制”。

梯度累加实验分别重新计算两次平方损失。参数 3 的梯度依次为 6、12，设置 `.grad=None` 后再次反向为 6。这与是否保留同一次计算图是两个不同问题。训练每次重新前向，在 `no_grad` 中更新参数，避免把参数更新也记入训练图。

## 4. 训练与数据隔离

160 个样本由局部 CPU Generator 生成；真实参数和噪声强度记录在结果中。预先固定 96/32/32 划分，不进行测试集调参。只有训练片段参与损失反向与最小二乘参考拟合；常数基线也只使用训练目标均值。验证与测试片段只用于报告。

单个合成分布帮助检查优化器实现，无法验证真实任务鲁棒性。没有数据集授权、下载或个人数据问题。后续真实数据实验需另外记录来源、许可证和数据预处理。

## 5. 可复现边界

本例固定数据 Generator、CPU、float64 和配置，连续两次运行的 SGD 参数与损失在本环境逐位一致，且不修改调用者的全局 PyTorch RNG 状态。不同版本、数学库、硬件可能不相同；`lstsq` 用容差对照，不承诺逐位相等。JSON 记录时间和环境，因此文件本身当然不会每次完全一致。

## 6. 失败不是隐藏结果

非法维度、目标隐式广播、混合 dtype、NaN/Inf、无效步数或学习率会明确失败。输出文件采用独占创建保护已有证据。实验检查不通过时 CLI 返回非零退出码。未验证 CUDA、AMP、分布式和生产负载；这些属于后续能力目标。

## 7. Module 与小批次扩展

新增实现未修改以上手写基线。注册参数、局部 loader 随机状态、train/eval、尾批加权和同遍历次数比较的完整设计见 [模块化小批次训练](minibatch-training.md)。默认96条训练数据分为20+20+20+20+16，不丢尾批；固定模型评估与更新中的在线损失分别记录。
