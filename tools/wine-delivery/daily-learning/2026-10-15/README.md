1. 固定整包 SHA-256，并对同一份已校验字节进行 ZIP 检查。
2. 校验全部文件清单和哈希，拒绝路径越界、重复/大小写冲突、符号链接、NUL 截断、文件/目录冲突、不支持的压缩和超限文件。
3. 只写入新目录，不覆盖旧文件；执行后逐一确认原交付文件未变化。
4. 运行原 README 命令，额外从无关工作目录运行 worker，排查隐藏的相对路径依赖。
5. 为报告检查已知协议、fixture、控制字段、Boolean 类型和科学哈希；将交付通过与科学比较分别输出。
6. 失败时保留已有报告；测试包含非零退出、超时、缺失输入、非有限 JSON、控制矛盾等情况。
