## Actual experiment and independent equations

[Full report](2026-11-02-training-diagnostics.json) was generated by the actual module
CLI and its bytes parse to the same object as stdout. Three controlled paths each
execute 12 measured steps, for 36 records, using the predeclared five-row dyadic fixture.
Correct training loss decreases from 2.25 to 0.16071347777446246. Both omitted-operation
paths retain 2.25 and zero parameters, but differ in absent versus present gradients.
These are observations on one fixture, not estimated classifier accuracy or a
benchmark of training performance.

Core tests independently check scalar MSE and SGD equations across nine configurations
(three learning rates, three paths), 108 steps, atol=rtol=1e-12. The separate independent
review repeats a closed-form oracle and tests deceptive labels and optimizer mutations;
its [28-test report](2026-11-02-training-diagnostics-independent-review.md) states the
scope. Those counts are subsets, not extra reported tests or independent datasets.

The diagnostic API receives only measured counts and norms. It cannot uniquely infer
omitted backward or omitted step from symptoms. Missing versus zero gradients, partial
gradients, externally induced updates and positive-gradient/no-update ambiguities are
explicitly represented. No arbitrary-model convergence or cross-platform equality claim.
